# 🤔 Varoluşsal Kriz Üreteci

## Bilimsel Giriş (Ciddiye Alınız)

Bu repository, modern insanlığın en büyük sorununa çözüm üretmek amacıyla oluşturulmuştur: **Yeterince varoluşsal kriz geçirmemek**.

Yıllar süren (asılında 7 dakika) araştırmalar sonucunda, uzmanlarımız (ben) şunu keşfetti: İnsanlar günde en az 3 varoluşsal kriz geçirmezse, hayatlarının anlamını unutuyorlar. Bu program, o krizi size hediye eder.

## Özellikler

- Rastgele kriz üretimi (gerçekten rastgele, quantum seviyesinde)
- 3 saniye düşünme süresi (evrenin onayı için)
- Sonsuz tekrar edilebilirlik (terapi yerine geçmez, daha kötüsünü yapar)
- Hiçbir şey çözmez. Tam tersine.

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/varolus-krizi-ureteci.git
cd varolus-krizi-ureteci
python kriz_ureteci.py
```

Program çalıştıktan sonra, krizle başa çıkamıyorsanız doktorunuza danışın. Veya tekrar çalıştırın.

## Uyarı

Bu yazılım hayatınızı değiştirebilir. Genellikle kötüye. Kullanımınızın sorumluluğu size aittir. Evren de sizi izliyor olabilir.
